# 🎯 Анти-ИИ Визометр

Офлайн-веб-приложение для тренировки навыка отличать реальные фотографии от ИИ-генераций. Работает полностью автономно, без серверов и интернета.

🔗 **[Играть онлайн](https://anti-ai-visometer.vercel.app/)**

---

## ✨ Особенности
- 🔊 Звуковой фидбек при правильном/неправильном ответе
- 📂 4 тематические категории: Животные, Природа, Города, Еда
- 🎚️ 3 уровня сложности: Лёгкий / Средний / Сложный
- 💾 100% офлайн-режим: работает через `file://` без локального сервера
- ⚡ Чистый Vanilla JS / HTML5 / CSS3, без зависимостей и фреймворков
- 📱 Полностью адаптивный дизайн (мобильные + десктоп)
- 🔍 SEO-оптимизация: Open Graph, Twitter Cards, JSON-LD, `robots.txt`, `sitemap.xml`
- 🛡️ Встроенный fallback: автоматическая замена `.jpeg` → `.jpg` при ошибках загрузки
